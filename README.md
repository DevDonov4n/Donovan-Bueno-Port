## 🚀 Sobre o projeto

Este é o meu portfólio pessoal, desenvolvido para apresentar minha trajetória, habilidades e projetos na área de desenvolvimento de software.

Mais do que apenas reunir meus projetos, a proposta foi transformar o próprio portfólio em uma demonstração prática daquilo que venho aprendendo e desenvolvendo durante minha jornada na tecnologia.

O projeto possui uma interface moderna, responsiva e interativa, com foco em uma experiência de navegação simples e agradável.

> Este projeto está em constante evolução, assim como minha jornada como desenvolvedor. 🚀

---

## 🎯 Objetivo

O principal objetivo deste projeto é apresentar:

- Minha trajetória na área de tecnologia
- Minhas principais habilidades
- Tecnologias que estou estudando
- Projetos desenvolvidos
- Experiências e formação
- Meios de contato profissional

Além disso, o portfólio serve como um espaço para colocar em prática conceitos de **desenvolvimento web, componentização, responsividade, UI/UX e interatividade**.
